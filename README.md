# court — дебаты AI-агентов

CLI-инструмент, в котором несколько AI-агентов (потенциально на разных моделях
и у разных провайдеров) обсуждают один вопрос: обмениваются мнениями, спорят,
корректируют позиции. Агент-модератор подводит итоги раундов, фиксирует
консенсус и выносит финальное решение.

## Как это работает

1. Вы задаёте вопрос и описываете участников в `config.yaml` — у каждого своё
   имя, персона (позиция/характер), модель и провайдер.
2. Дискуссия идёт раундами: каждый агент видит полный протокол и отвечает
   на аргументы остальных.
3. После каждого раунда модератор подводит итог и решает, достигнут ли
   консенсус — если да, дебаты завершаются досрочно.
4. В конце модератор выносит вердикт: согласованный ответ, ключевые аргументы
   и оставшиеся разногласия.

## Установка и запуск

```bash
go build -o court ./cmd/court

export ANTHROPIC_API_KEY=sk-ant-...
export OPENAI_API_KEY=sk-...   # если в конфиге есть openai-агенты

./court "Стоит ли нам переходить с монолита на микросервисы?"

# с сохранением протокола и своим конфигом
./court -config config.yaml -out debate.md "Ваш вопрос"
```

## Конфигурация

```yaml
rounds: 3            # максимум раундов (при консенсусе завершится раньше)

moderator:
  name: Модератор
  provider: anthropic
  model: claude-opus-5
  persona: Беспристрастен, ценит аргументы по существу.

agents:
  - name: Прагматик
    provider: anthropic
    model: claude-opus-5
    persona: Опытный инженер, интересуют сроки, стоимость и риски.

  - name: Скептик
    provider: openai
    model: gpt-4o
    api_key_env: OPENAI_API_KEY
    persona: Ищет слабые места и скрытые допущения.
```

Поля агента:

| Поле | Описание |
|---|---|
| `provider` | `anthropic` или `openai` (любой OpenAI-совместимый API) |
| `model` | id модели у провайдера |
| `persona` | системная инструкция: позиция и характер агента |
| `base_url` | для `openai`: адрес совместимого API (Gemini, Ollama, OpenRouter…) |
| `api_key_env` | имя env-переменной с ключом (по умолчанию SDK берёт стандартную) |
| `max_tokens` | лимит ответа, по умолчанию 4096 |

Примеры `base_url` для OpenAI-совместимых провайдеров:

- Gemini: `https://generativelanguage.googleapis.com/v1beta/openai/`
- OpenRouter: `https://openrouter.ai/api/v1`
- Ollama (локально): `http://localhost:11434/v1`

## Структура проекта

```

internal/config/  загрузка и валидация YAML-конфига
```
